# Работа ломбарда

Рондаков Тимофей Сергеевич, ИКБО-15-24. Учебная практика, этапы 2 и 3.

Python 3.10 или новее. Внешние библиотеки не нужны.

Из корня проекта:

```text
python3 src/main.py --as-of 2026-10-05
python3 -m unittest discover -s tests -v
```

В Windows вместо `python3` можно использовать `py`.

`src/main.py` — процедурные функции; `data/loans.json` — вымышленные записи;
`tests/test_main.py` — 16 проверок; `docs/` — схемы и пояснения.

Суммы и ставки задаются строками, ставка 0.001 означает 0.1% в день.
День выдачи исключен, день расчета включен. Проценты простые, округление
ROUND_HALF_UP до копейки только после ограничения начислений.
Частичные платежи, продление и автоматическая продажа не реализованы.
Предельный коэффициент задается в записи; это учебная параметризация,
а не полноценная проверка ПСК или нормативного соответствия.
`grace_until` — включительная дата окончания льготного срока, определенная
по условиям договора. Она не заменяется условными 30 днями.
`redeem` возвращает копию записи; демонстрация не записывает изменения на диск.
При повторном запуске используются исходные данные.

Реальных клиентов и паспортных данных нет.
